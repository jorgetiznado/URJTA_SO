# Casos de NyR

Los casos reales que Danna trae para revisar con Claude: una orden rara, un operador que se
equivocó, un resultado que no cuadra. Cada uno enseña algo, y cuando un tipo de caso se repite se
convierte en una **habilidad** (ver `CLAUDE.md`, sección 7).

**Dos lugares:**
- El **detalle** (capturas, servicio, dirección, fotos, Excel) va a `danna/datos/casos/AAAA-MM-DD_tema/`,
  que no se sube a git.
- **Aquí** solo va lo que se aprende, sin datos que identifiquen al cliente (ni servicio, ni orden,
  ni nombre, ni dirección, ni RUT).

Formato:

```
## AAAA-MM-DD — tema corto
**Carpeta:** danna/datos/casos/AAAA-MM-DD_tema/
**Qué pasaba:** el problema, en general.
**Cómo se vio:** qué se miró (archivo, pantalla de NyR, script) y qué mostró.
**Qué se hizo:** la solución, o "pendiente" / "idea para Jorge".
**Lo que enseñó:** la regla o el patrón.
**¿Habilidad?:** no / candidata / sí → nombre
```
